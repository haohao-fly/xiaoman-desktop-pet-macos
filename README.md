# 小满桌宠

一个原生、离线运行的 macOS 桌面宠物。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

小满会停在桌面上眨眼、挥手，也会自己散步。她的动作来自一张 8×11 的透明精灵图，程序由一个 Objective-C 源文件完成窗口、动画、拖动、菜单和自动活动，不需要 Electron，也不依赖第三方运行库。

> 这个仓库保存的是可重复构建的源码。桌面上的 `小小桌宠.app` 是由同一份源码打包出的本地版本。

## 小满是什么

小满是一个常驻桌面的轻量角色。应用没有 Dock 图标，窗口透明并保持浮动；关闭 Codex 后，她仍能独立运行。

目前接入了 9 类标准动作和一组 16 方向环视动画：

- 待机眨眼
- 向左、向右跑动
- 挥手
- 跳跃
- 难过
- 等待
- 忙碌
- 认真检查
- 环视四周

单击小满会触发挥手。右键可以直接选择动作，也可以暂停自动活动。

## 为什么做这个版本

最早的独立版已经能显示小满，也能被拖动和单击。精灵图里的大部分动作没有接入，所谓“自动散步”只是整个透明窗口横向滑动，角色本身仍停留在待机画面。

这次更新把动画素材和桌面行为真正连在一起：移动方向决定跑步方向，非循环动作播放结束后回到待机，用户也能从右键菜单检查每一个动作。

## 1.1 更新了什么

### 所有动作都有入口

右键菜单新增“播放动作”，待机、左右跑、挥手、跳跃、难过、等待、忙碌、检查和环视均可手动触发。空闲时，小满也会随机散步或播放一个表情动作。

### 散步不再是平移贴图

自动散步会根据目标方向播放向左或向右跑动，窗口移动和动画时长保持一致。到达屏幕边缘时会自动换向，动作结束后恢复待机。

### 动画使用各自的帧时长

待机、跑动、挥手等动作不再共享固定帧率。每一行动画按自己的节奏播放，最后一帧会适当停留，动作看起来更完整。

### 拖动和多屏行为更稳

- 增加 3 像素拖动阈值，轻微手抖不会误判为拖动；
- 拖到屏幕外后松手，小满会回到当前屏幕的可见区域；
- 自动活动使用小满所在的显示器，不会因为鼠标停在另一块屏幕而突然跳过去；
- 用户在跑动途中开始拖动或打开右键菜单时，会中止自动位移，避免窗口继续抢位置。

### 补上启动和运行保护

- 启动时检查精灵图是否存在，并验证为 `1536×2288`；
- 定时器在退出时主动停止；
- macOS 普通打开只保留一个桌宠实例；
- 构建时清理旧产物，避免旧资源残留；
- 构建继续启用编译警告即错误和本地临时签名。

## 操作

| 操作 | 结果 |
| --- | --- |
| 左键单击 | 挥手 |
| 左键拖动 | 移动桌宠 |
| 右键 → 播放动作 | 手动选择动画 |
| 右键 → 暂停自动活动 | 停止随机散步和表情 |
| 右键 → 退出桌宠 | 退出应用 |

## 系统要求

- macOS 13 或更高版本
- Apple 芯片 Mac
- Xcode Command Line Tools（仅自行构建时需要）

应用不联网，不申请摄像头、麦克风、定位或后台网络权限。

## 构建

```bash
cd 源码
chmod +x build.sh
./build.sh
```

构建结果位于：

```text
源码/build/小小桌宠.app
```

首次运行如果被 macOS 阻止，请在 Finder 中右键应用，选择“打开”。这是因为本项目使用本机临时签名，没有使用 Apple Developer ID 公证。

## 项目结构

```text
.
├── README.md
├── 使用说明.md
└── 源码
    ├── Sources/main.m
    ├── Resources/spritesheet.png
    ├── Info.plist
    └── build.sh
```

核心代码集中在 `main.m`：`PetView` 负责帧动画和鼠标交互，`AppDelegate` 管理透明窗口、自动活动、屏幕边界和应用生命周期。
